## Ideas previas (v1.x)

## Versión 1.1 (Corto Plazo — Próximas 4 semanas)
- [ ] **WhatsApp Business Cloud API (Opcional):** Posibilidad de conectar la API de Meta para enviar mensajes con botones interactivos cuando el volumen del salón lo justifique.
- [ ] **Galería Fotográfica de Resultados:** Almacenamiento de fotos antes/después asociadas a cada visita para apreciar la evolución del color.
- [ ] **Etiquetas Personalizadas para Clientas:** Tags como "Rubias", "Canas rebeldes", "Tratamiento ácido", "Alérgica a amoníaco".

## Versión 1.2 (Mediano Plazo — Próximos 2 a 3 meses)
- [ ] **Integración con Boleta Electrónica SII (Chile):** Conexión con proveedores de facturación electrónica (como Bsale o SimpleBoleta) para emitir boletas electrónicas exentas o afectas directamente al registrar el cobro en CLP.
- [ ] **Soporte Multi-Estilista / Sillón de Peluquería:** Permitir a salones pequeños gestionar comisiones de varios estilistas bajo una misma cuenta matriz.
- [ ] **Asistente de Colorimetría:** Sugerencias de neutralización según el círculo cromático y altura de tono de base.

## Versión 2.0 (Largo Plazo)
- [ ] **Portal de Auto-Agendamiento:** Enlace web público donde las clientas pueden consultar la disponibilidad de su estilista favorita y reservar su hora.
- [ ] **Expansión a otros nichos de estética en Chile:** Barberías, manicuristas (NailTrack) y pestañas/cejas (LashTrack).
